# Issue 83: nono-here

## Goal

Launch OpenCode for the current Git workspace through its repository-local nono profile, with native host-side lifecycle hooks.

## Milestones

1. Add `nono-here.sh` with Git-root/PWD detection, profile validation, argument forwarding, and exit/signal propagation.
2. Register the existing before/after scripts as native nono session hooks with bounded timeouts.
3. Add shell-level wrapper tests and validate the profile with the installed nono CLI.
4. Document usage and hook trust/failure semantics.

## Verification

- `bash tests/nono-here-test.sh`
- `nono profile validate .nono/profile.json`
- `nono run --profile .nono/profile.json --workdir "$PWD" --allow-cwd --dry-run -- opencode`

## Review Log

- **2026-08-24 — Reviewer: APPROVED.** All four milestones satisfied. Implementation is correct, secure, and tested. Minor note: unknown flags before `--` are silently forwarded to opencode rather than rejected — acceptable given documented `--` convention.

## Expectation vs. Reality

The issue suggested wrapper-managed hooks analogous to `sbx-here`. Nono already
provides native session hooks with host execution, timeouts, environment export,
and exit metadata, so the implementation delegates lifecycle handling to nono.
